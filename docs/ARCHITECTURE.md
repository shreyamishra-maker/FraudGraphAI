# FraudGraph AI architecture
Trigger → Case → TigerGraph investigation → GraphRAG → Pattern assessment → uncertainty gate → controlled evidence request → policy engine → next-best action → explanation → case memory.
TigerGraph/GSQL performs relationship traversal and graph analysis. GraphRAG retrieves only relevant graph evidence, policy, typologies and closed cases. The LLM is used for tool selection, synthesis and explanations, not to replace graph analysis. R1–R10 remain deterministic policy controls.
